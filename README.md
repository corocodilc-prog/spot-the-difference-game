Twinkle Toys — Spot the Difference: three original hand-drawn scenes (The Toy Shop Window at dusk, The Astronomer's Rooftop at night, The Lighthouse Keeper's Kitchen in the morning), each hiding seven fair differences between two pictures side by side. Click a difference on either picture to ring it on both, watch the "to go" counter fall, and finish the scene for stars. Keyboard play (arrow keys + Enter), hints, a 2x magnifier lens, a timer, streak scoring and synthesized WebAudio sounds — no files, no network, no libraries. Every picture is drawn fresh from code on a canvas, so the game runs from static files alone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game plays in desktop Chrome with no network request.
